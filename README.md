# Vortex Collective

A responsive, single-page portfolio for Vortex Collective.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Before launch
- Replace the four clearly labeled concept projects with real work when available.
- Replace `hello@vortexcollective.studio` with the studio's real contact email.
- Add real social links and project case-study pages.
- Add final project imagery and any required image credits.

## Deploy
This is a static site and is suitable for Cloudflare Pages. Connect the GitHub repository, choose **Direct Upload** or **Connect to Git**, and use the repository root as the build output directory. No build command is needed.
